How the school uses ITEC (full flow)

One student record moves through the whole school. Do not skip steps.

1. Super Admin sets up campus, courses, fees, and rules
2. Pedagogical creates professors and assigns classes + timetable
3. Registry registers the student, then enrolls in course/class
4. System creates fees → Finance confirms payments
5. Professor enters grades (semester must be Open)
6. Student & Parent see grades and fees
7. Direção approves scholarship (Bolsa) when requested

Quick help

Grades blocked? Open the semester in Super Admin Regras, and check professor grade permission.
Wrong fees? Check Super Admin fee list and Mandatory toggle before enrollment.

1. Super Admin setup

Super Admin sets up everything first: Campus/Polo, Courses + Levels, Fees master, Scholarship types, and Grade permissions. Only Super Admin creates campuses and courses — other roles only select from the list.

2. Academic Registry — students

Step 1 Register: name, DOB, phone, parent info. Step 2 Enroll: Course + Level + Class + Plan. Challan is auto-created from Fees master. Registry can also allocate subjects, change status, and request scholarship.

3. Scholarship approval

Registry submits the request → Direção (Directorate) approves → Finance auto-applies the discount on the challan. Registry never approves.

4. Professor grading

Final Average = (Best of T1/R1 + Best of T2/R2 + Exam) ÷ 3. Grades save only if the semester cycle is OPEN and the professor has permission. If either fails, the grade is blocked with an error.

5. Student progression & backlogs

Pass some subjects → move on with backlogs. Pass ≥ 3 subjects → next Level/CV. Fail ALL → repeat level. Backlogs carry forward until cleared. Final year has limited attempts (default 3) and set by Super Admin. Clear all backlogs + pass level → Graduated. Exceed attempts → profile expired.

6. Payment flow

Student opens the fee row and pays (checkout). When payment succeeds, the fee is marked PAID, Finance can also confirm payments manually.

7. Semester & cycle

1 Level = 2 Semesters (example CV1 = Year 1 = Sem1 + Sem2). Super Admin opens or closes each cycle. Closed cycle = all grades locked.

8. New academic year

Super Admin sets the new year. Registry creates new classes. Old data stays for history. Passed students → next level. Failed students → repeat level. New students → Level 1.

Super Admin — First setup

For: School system manager

Simple flow

  1. Create users and roles so staff can log in
  2. Add campuses (Polo), courses, and levels
  3. Set academic rules and open/close semesters
  4. Configure fees, late fees, and scholarship types
  5. Send mass emails when needed

Tip: Do Super Admin setup before anyone enrolls students.

Painel principal

Home screen after login. Shows shortcuts and a quick view of school settings. Use the left menu to open each setup screen.

Usuários

Create staff and student logins. Choose email, name, role, and campus when needed. Without users, other people cannot enter the system.

Papéis (Roles)

List of roles (Admin, Registry, Finance, etc.). Each role controls which menu that person sees.

Permissões

Turn modules on or off for each role (Students, Fees, Calendar, Reports…). Save after changes.

Novo Envio (Mass email)

Send a message to students, parents, or professors. Filter by campus, course, or level. Email works. Choose audience carefully before sending.

Histórico de Envios

Past mass messages. Open a row to see what was sent and to whom.

Configurações Financeiras

Money rules for the whole school: payment mode (manual/automatic), late fees, monthly tuition, extra fees (emoluments), and scholarship types. Set these before enrollment so bills are correct.

Polo (Campus)

Add or edit campuses. Registry only selects from this list when registering students.

Regras Académicas

Set max absences, minimum subjects to pass a level, and open/close semester cycles. When a cycle is Closed, professors cannot change grades.

Permissões de notas

Decide which professor can edit grades for which campus, course, and class. If permission is off, grade save is blocked.

Cursos e Níveis

Create courses, then add levels in order (CV1 → CV2 → CV3). This order decides how students progress.

Logs do Sistema

Activity history. Filter and export when you need to check who changed what.

Exportar

Export tools screen for downloading data when needed.

Why this exists: Client requested that if the screen is only for export, the tab should be named Export (Exportar).

Definições Gerais

School name, contacts, academic year, and communication options. Change the academic year here when a new year starts.

Marca (Brand)

Upload logo and brand images used on login and in the system.

Registo Académico — Students & enrollment

For: Academic Registry staff

Simple flow

  1. Register the student (personal details only)
  2. Open student profile → Enroll (course, level, class, payment plan)
  3. Fees are created automatically from Super Admin fee list
  4. Request scholarship if needed (Direção approves)
  5. Change student status when required (dropout, transfer, etc.)

Tip: Always enroll in two steps: Register first, then Enroll. Do not skip Super Admin setup.

Dashboard

Overview of students and quick access to daily registry work.

Estudantes

Student list. Click Add to register a new student (name, contacts, parent, campus). Click a student to open the profile for enroll, status change, or documents.

Bolsa (Request scholarship)

Create a scholarship request for a student. You submit — Direção approves or rejects. You cannot approve here.

Disciplina

Manage subjects and link them to courses/levels so grades and class work use the right subject list.

Curso

View or manage courses used for enrollment (master courses usually come from Super Admin).

Turma (Class)

Create classes for the academic year: course, level, campus, shift, capacity. Students enroll into these classes.

Calendário

See school calendar events. Creating events is mainly for Admin, Pedagogical, or Secretaria.

Mensagem

In-app chat with staff and students for day-to-day communication.

Relatório

Registry reports and filters for student/academic data.

  4. Manage analytical lesson plans
  5. Review evaluations submitted by students

Tip: Until a professor is assigned to a class, that professor will not see those students.

Estudantes

Professores

Horário

Build the school timetable: day, time, class, subject, professor. Students and professors then see their schedule.

Calendário

Create and manage school calendar events.

Plano analítico

Analytical plans for teaching. Parents can also view related plans in their portal.

Avaliação

See student evaluation / feedback forms that students submitted.

Mensagem

Chat with other staff and students.

Relatório

Pedagogical reports.

Professor — Teach your classes

For: Teachers

Simple flow

  1. Open Estudantes — only your assigned classes appear
  2. Enter grades when the semester cycle is Open
  3. Add lesson plans for your subjects
  4. Check your timetable and calendar
  5. Chat with your classes

Tip: If grades will not save: ask Super Admin to open the semester and check your grade permission.

Dashboard

Your teaching home. Useful after you are assigned to classes.

Estudantes & grades

Only students in your assigned classes. Open a student to enter Test 1, Retake 1, Test 2, Retake 2, and Exam. The system calculates the final average. Pass mark is 10/20.

Financeiro (your salary)

Your own salary / financial view — not student fees.

Horário

Your teaching timetable built by Pedagogical management.

Avaliação

View evaluations related to your teaching.

Calendário

School events (view).

Plano de Aulas

Create and edit lesson plans for your assigned subjects/classes.

Mensagem

Chat grouped by your classes (Minhas Turmas).

Finanças — Fees & payments

For: Finance staff

Simple flow

  1. Open Estudantes to see fee bills
  2. Generate challan / PDF when needed
  3. In manual mode, mark paid / pending / overdue
  4. Apply authorised discounts when allowed
  5. Follow late fees shown on the bill

Tip: Bank auto-deposit is still pending. Use manual confirmation for daily payments until bank connection is finished.
